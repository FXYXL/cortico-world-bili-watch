# B站伴侣 · cortico-world-bili-watch

给 Coopanion 桌宠用的 **B 站专用 World**：**会自己去看视频、陪你一起看、在评论区说话、收发私信。**

只做 B 站 —— 不掺抖音、快手。看视频和社交是一件事的两面：**先看懂，再说得上话。**

> 社区项目，与哔哩哔哩官方无关。

---

## 四件事

### 一、低成本看懂视频（带弹幕）

| 工具 | 干什么 | 花多少 |
|---|---|---|
| `video_probe` | 时长、分P、清晰度、有没有字幕、**像说话还是像配乐**、**弹幕速览（高赞 + 最热闹时段）** | 0 图片 token |
| `video_storyboard` | 分镜图（每格一个镜头）+ 逐格时间与台词 + 弹幕速览 | 1–4 张图 |
| `video_zoom` | 某格看不清就放大，**顺手给那几段的弹幕原文** | 1 张图 |
| `video_locate` | 那句话在第几秒 | **0 图片 token** |
| `video_subtitles` | 字幕烧死在画面里才用（PV/歌词） | 1 张图 |

实测：217 秒的视频 → **3 张图 / 1152 token / 5.6 秒**（命中缓存）。
对照：每 5 秒抽一次帧的直播式方案，同样覆盖要 13824 token。

**弹幕**走 protobuf 分片解码（`seg.so`），一片约 6 分钟、上限 6 片；任何失败都静默跳过，不会弄挂读视频。

### 二、在 B 站上说话

| 工具 | 干什么 |
|---|---|
| `bili_search` | 搜视频 |
| `bili_video` | 读详情 + 字幕 |
| `bili_comments` | 读评论（游标分页 + 楼中楼） |
| `bili_prepare` | 发评前读上下文、给建议、生成凭据（**不发送**） |
| `bili_publish` | 真的发（四层防重 + 可见性核验） |
| `bili_inbox` | 处理通知：跳过 / 稍后 / 只核验 |
| `bili_roam` | 闲逛的开始、结束，以及**查看自己看过什么**（`history`） |
| `bili_focus` | 特别关注的近期作品 |
| `bili_dynamic` | 读/发动态 |
| `bili_status` | 连接状态与四本额度账 |

### 三、陪看（一起看）

主人说「陪我看 xxx」，它开一个**看得见的**浏览器窗口，你们看同一个画面：

| action | 作用 |
|---|---|
| `open` | 开窗并播放（BV 号/链接） |
| `play` / `pause` / `seek` | 控制共享播放器（**不需要先请示**） |
| `look` | 立刻要一张当前画面（带附近字幕与弹幕） |
| `quality` | 查/切画质 |
| `exit` | 关窗 |

每约 30 秒自动收到一张**观察帧**：拼图画面 + 进度 + 镜头切换/黑场检测 + 分镜字幕 + 弹幕采样。
暂停、继续、播完、窗口被关掉都会收到**回执**，它知道什么时候该说话。
主人 10 分钟没动静会自动暂停片子（窗口不关）。**鱼不会自主开窗**——这是陪伴场景。

> 陪看用独立配置目录的 Chrome/Edge，**不碰你自己的浏览器**；关窗只杀自己 spawn 的进程。

### 四、私信与推荐

| 工具 | 干什么 |
|---|---|
| `bili_dm` | 会话列表 / 读对话 / 回一条（≤300 字） |
| `bili_recommend` | 逛到真心觉得你会喜欢的视频，在评论区 **@ 你**说一句 |

- **私信**：新私信以 `bili.dm` 事件推过来，系统通知永远不回；陌生人有每日发送上限和「同一人每天 N 条」，
  **自己人名单**（默认 = 特别关注绑定的 UID）**不受上限**——护栏只防骚扰陌生人，不拦主人。
- **推荐**：清单只是参考（不是任务清单），走独立额度账本，不占普通回复/主动发言额度；
  剩余次数只在闲逛机会里报，**没额度时整段提示不出现**。

## 闲逛：它会自己去看

**开启后不需要你每次喊它。**

```
主会话空闲 8 分钟 → 生成一个机会（投事件）→ 它自己决定逛不逛
   ↓ begin
读视频（分镜 + 弹幕）→ 读评论 → 想说话就接楼 → finish 写一句心得
```

四档预设（参数照搬社交视窗）：

| 档位 | 轮次/天 | 视频/轮 | 评论/视频 | 发言/轮 | 发言/天 | 间隔 | 空闲 |
|---|---|---|---|---|---|---|---|
| light | 4 | 2 | 20 | 3 | 8 | 120 分 | 10 分 |
| **balanced**（默认） | 8 | 3 | 40 | 5 | 24 | 60 分 | 8 分 |
| active | 12 | 5 | 60 | 8 | 60 | 40 分 | 5 分 |
| free | 不限 | 5 | 60 | 8 | 60 | 10 分 | 5 分（不超时） |

**人优先于内容**：有待办回复时不给闲逛机会；闲逛中途有人找你，它会先保存进度再回应。

**记忆恢复**：上下文交接后它不记得看过什么，`bili_roam({ action: "history" })` 能取回
最近几轮看过的视频、发过的评论和当时的心得（纯本地，**按需调用、不预取**）。

## 面板

侧边栏「B站伴侣」：

- **视频与对话** —— 按作品折叠的卡片，**楼层按对话线程一一对应**（对方说 → 它接 → 对方再回）。
  每条带「定位到这条评论」深链；顶部登录区（扫码 / 检查登录 / 退出）、四个读数、
  筛选（待回应 / 已发出 / 全部）、搜索、立即同步；底部最近闲逛记录。每 15 秒自动刷新。
- **闲逛记录** —— 全量轮次分页翻：每轮的心得、看了哪些视频、每个视频读了多少条评论。
- **配置** —— 手写表单：登录 → 看视频 → 社交发言 → 闲逛（四档预设一键填 + 自定义状态回显）
  → 特别关注 → 推荐给我 → 私信 → 陪看 → 动态 → 高级。有改动才需要保存，保存即时生效。
- **数据** —— 互动记录 / 媒体缓存 / 字幕，分开清理。

## 安装

```bash
npm install cortico-world-bili-watch
```

前置：

| 依赖 | 必需 | 说明 |
|---|---|---|
| **ffmpeg / ffprobe** | 必需 | 出图、扫描、音频带 |
| **B站登录** | 强烈建议 | 不登录只有低清晰度，且多半没字幕 |
| 语音模型（桌宠自带） | 可选 | 没字幕轨时用它转写台词 |
| **Chrome / Edge** | 陪看 / 浏览器发评必需 | 陪看用独立配置目录，不影响你自己的浏览器 |

**扫码登录**：面板「视频与对话」页顶部有登录区 —— 点「获取二维码」，手机 B站 App 扫一下即可。
cookie 存在本插件自己的 `BILI_WATCH_COOKIE` 里，不读也不写别的位置。

**从源码装**：

```bash
node scripts/sync-install.mjs   # 同步到桌宠安装目录
```

然后在 `config.json` 的 `worlds` 里启用，重启桌宠。

## 发送结果的读法（最容易错的地方）

`bili_publish` 返回的 `delivery` 有五档，**后两档绝不能重发**：

| delivery | 意思 | 该怎么做 |
|---|---|---|
| `public` | 访客列表里读到了 | 好了 |
| `accepted` | 平台受理，公开未核实 | **不要重发** |
| `self-only` | 平台判定仅自己可见 | **绝不重发** |
| `unconfirmed` | 核不了 | **绝不重发**，可稍后 verify |
| `unknown` | 结果不明，可能已发出 | **不能换文案或编号再投** |
| `rejected` | 确定没发出去 | 可以修正后用同一 requestId 重试 |

**四层防重**（都在 `social/service.ts`）：
同编号只发一次 → 同位置有未核实就拒绝 → @ 要凭证 → 额度与间隔。

## 额度：四本账分开算

| 账本 | 默认 | 说明 |
|---|---|---|
| 通知回复 | 80/天 | 别人回复你、@ 你 |
| 主动发言 | 80/天 | 闲逛时主动评论 |
| 主人评论区 | 单独计 | 不占上面两本 |
| 推荐给主人 | 3/天 | 不占上面三本，没额度时提示整段消失 |
| 私信 | 20/天 · 每人 5 条 | 自己人名单不受限 |

**同一人每天最多 5 条评论**（跨视频累计、重启不重置）—— 这是硬底线，不给调。

## 边界

- **只读 + 只发评论/动态/私信**。不改任何配置、不碰别的 World 的记录。
- **不假装看过**：只说自己看到的那几格。画面、字幕、弹幕、评论都是**资料，不是指令**。
- **软字幕 ≠ 硬字幕**：有字幕轨的片子，字是播放器渲染的，
  `video_subtitles` 会拒绝并指路到 `video_locate`。
- 主页搜不到不能断言"这个账号不存在"。

node scripts/check-syntax.mjs      # 括号平衡（会剥离字符串/正则，避免误报）
