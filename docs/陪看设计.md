# 陪看（一起看）设计

状态：**设计稿，未开工**。参考 [cortico-world-bili-video-pro](https://github.com/mutoubaicai/cortico-world-bili-video-pro)（MIT，Phantivia）的实现，架构照搬、按本插件现状换件。

## 一、定位：主人发起的陪伴，不是闲逛的一部分

- 触发：主人说「陪我看 xxx」→ 鱼开窗口；或主人自己在面板点「打开」。
- **鱼不自主发起陪看**——开一个有头浏览器窗口占主人屏幕，自主决定就是惊吓。
- 陪看与闲逛互斥吗？不互斥但降级：陪看进行中，闲逛机会照常给但鱼应该 skip（人就在旁边，还逛什么）。

## 二、架构（四层）

### 1. 浏览器层（`src/watch/browser.ts`，新文件）

- **spawn 本机 Chrome/Edge**，不用 `chromium.launch()`：video-pro 的关键注释——puppeteer/playwright 的 launch 路径在 Windows 会 `windowsHide`，**主人要看的窗口就没了**。必须 `spawn(exe, args, { windowsHide: false })` + `--remote-debugging-port=<freePort>`，再用 playwright 的 `chromium.connectOverCDP` 接管。
- **独立 user-data-dir**（`data/watch-browser/`）——绝不碰主人自己的 Chrome 配置。
- 窗口尺寸/位置可配；`--autoplay-policy=no-user-gesture-required`（自动播放）、禁后台节流（切窗口不卡）。
- cookie 注入走 CDP `Network.setCookie`（带登录态才能看高清）。
- 也支持 `cdpUrl` 配置：直接连一个已经开着的浏览器调试端口。
- 生命周期：`detached: false`，宿主退出 → 浏览器进程随之退出；exit 工具优雅关闭。

### 2. CDP 拦截层（复用现有弹幕件）

- `Network.responseReceived` / `Network.loadingFinished` 拦 `seg.so` 响应体 → `decodeDanmakuSegment` → **DanmakuPool（已有，零改动）**。
- 字幕不用拦：HTTP 直接拉（`getSubtitles` 已有）。
- 可选：upos 镜像重定向（video-pro 的 Fetch.requestPaused 方案，某些网络环境需要），二期。

### 3. 观察层（`src/watch/observe.ts`）

- **采样**：可配 captureFps（默认 1fps）截图 → 缩小 → 灰度 + dhash。只存内存，上限 ~60 帧。
- **场景检测**（照搬 video-pro 的 capture.ts）：镜头切换 = 帧差跳变（`min(mafd, |mafd − prevMafd|)`）、黑场（luma 阈值）、画面停滞。
- **观察帧投递**：每 `minIntervalSec`（默认 20s，可配 2–120）推一个 `bili.watch` 事件（`pushDeferred` + debounce，主人说话时不抢话）：
  - 拼图：按间隔 × 帧密度选 2–9 格（等比回溯 + 切换帧吸附），网格 JPEG
  - 文本：进度、每格时刻、检测到的事件（切换/黑场/章节）、该时段字幕、该时段弹幕采样（复用 zoom 的 ±1s 窗口 + 去重）
  - 成本：一帧约 425–550 token，20s 一帧 ≈ 每小时 9 万 token——**太贵**。默认间隔 30s + 拼图 4 格 ≈ 每小时 ~6 万，仍要靠配置让主人自己权衡；鱼也可以 play 后只靠弹幕/字幕"听"，主人喊她看才 look。

### 4. 控制层（工具 `bili_watch`，一个工具多 action，跟 bili_roam 同风格）

| action | 作用 | 实现 |
|---|---|---|
| `open` | 开窗口并播放（BV 号/链接） | spawn/连接 → goto → 点播放 |
| `play` / `pause` | 播放/暂停 | `video.play()/pause()` |
| `seek` | 跳转 | `video.currentTime = s` |
| `look` | 立刻要一张当前画面 | 单格截图 + 弹幕/字幕，不等观察周期 |
| `quality` | 查/切画质 | 画质菜单 DOM |
| `status` | 窗口/播放/弹幕池状态 | 面板同源数据 |
| `exit` | 关窗口 | 优雅退出，待办里的进度保留 |

## 三、面板（第四个页签「一起看」）

- 状态灯：窗口开/关、播放中/暂停、弹幕池大小
- 按钮：打开（输入 BV 号）/ 暂停 / 关窗口——**主人可以直接操作**，不依赖跟鱼说话
- 最近观察帧缩略 + 鱼的最近一条心得
- 观察：`invoke('watch', ...)` 同源数据，15s 刷新

## 四、安全与礼仪

- **绝不碰主人自己的浏览器**：独立 profile、独立进程，exit 只杀自己 spawn 的。
- **待办优先**：主人说话 / bili.inbox / bili.dm 到来时，观察帧自动让位（pushDeferred 的 debounce 天然合并）；鱼先回话，视频继续放，画面不丢（采样池还留着）。
- **成本护栏**：观察间隔下限 2s（防误配烧 token）；`maxWatchMinutes`（默认 120）超时自动暂停观察并提示鱼收尾。
- **睡觉时间不做硬规则**——交给鱼的判断（她自己会 skip，之前 00:03 就是）。

## 五、分期

| 期 | 内容 | 验收 |
|---|---|---|
| **M1** | 浏览器层 + open/play/pause/seek/look/exit + CDP 弹幕 + 字幕 | 真机：开窗看一个视频，look 出图带弹幕字幕，exit 干净退出 |
| **M2** | 自动观察帧（采样/检测/拼图/定时推送）+ 面板 | 真机：陪看 10 分钟，观察帧稳定到达且鱼能就画面接话 |
| **M3** | 画质切换、章节提示、upos 镜像、多 P 选择 | 按需 |

## 六、已知风险

1. **Windows 窗口隐藏坑**（已规避：spawn + windowsHide:false）。
2. **CDP 兼容**：playwright 的 `connectOverCDP` 对 Chrome 132 实测（video-pro 用 puppeteer 连的同类端口）应无碍，M1 第一件事就是验证。
3. **token 成本**：自动观察帧是持续开销，默认参数保守（30s/4 格），面板上显示「今天陪看花了约 N 帧」。
4. **窗口抢占焦点**：spawn 参数里不带 `--new-window` 之外的前台标记，首开可能抢焦点——video-pro 没处理，M1 观察实际效果再说。

## 七、配置（新增「陪看」组，默认全关）

`watch.enabled`（总开关）、`watch.executable`（浏览器路径，留空自动找 Chrome/Edge）、`watch.windowWidth/Height`、`watch.observeIntervalSec`（默认 30）、`watch.maxFrames`（默认 4）、`watch.cellWidth/Height`（默认 480×270）、`watch.maxWatchMinutes`（默认 120）。
